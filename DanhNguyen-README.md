Iris Dataset
The Iris dataset contains:
•	150 samples
•	4 features
•	3 species
The three species are:
•	Setosa
•	Versicolor
•	Virginica
The four features are sepal length, sepal width, petal length, and petal width.
Main Results
The dataset contains 50 samples for each species. The scatter plot shows that Setosa is more separated from Versicolor and Virginica. There is more overlap between Versicolor and Virginica.
The mean sepal length is approximately 5.84 cm, and the standard deviation is approximately 0.83 cm.
